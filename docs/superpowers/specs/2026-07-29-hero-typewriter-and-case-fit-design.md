# Hero 打字动画与案例弹窗适配设计

## 目标

本轮修改解决三个明确问题：

1. “系统架构”案例长图在窄窗口或页面缩放状态下与弹窗容器错位。
2. 当前 Hero 暂停使用 Cycle 空间视角效果，最终画面只显示 `hero-poster.webp`。
3. Hero 主标题改为逐字输入，输入结束后光标闪烁约 1 秒再消失。

## 案例弹窗

### 根因

案例切片当前同时由容器 `aspect-ratio` 和图片 `height: 100%` 控制尺寸。弹窗、切片和图片形成三套独立的高度计算，在窄窗口、浏览器缩放及像素取整时可能出现不同步。

### 修改

- 桌面端文档宽度保持 `860px`。
- 实际宽度统一为 `min(860px, calc(100dvw - 24px))`。
- 切片不再建立强制宽高比盒子。
- 图片使用清单中的 `width`、`height` 属性保留尺寸信息，并以 `width: 100%; height: auto` 自然排列。
- 弹窗禁止横向溢出，切片之间不产生间隙。
- 关闭按钮仍固定在弹窗文档右上区域，不改变键盘关闭、焦点恢复和滚动锁定逻辑。

## Hero 最终画面

- Intro 视频及滚轮/触摸推进逻辑保持不变。
- 最终定帧只显示 `hero-poster.webp`。
- Cycle 视频文件、空间视角 Hook、映射模型和测试继续保留。
- Hero 内保留一个明确的 Cycle 功能开关，当前设为关闭；关闭时不请求、不挂载 Cycle 视频，也不接管鼠标或触摸事件。
- 后续重新启用时，只需打开功能开关并继续使用现有视角控制实现。

## 全页面鼠标光源

- 鼠标跟随素材替换为项目根目录中的 `light spot 02.png`。
- 素材复制到公开资源目录并使用稳定的英文文件名，源文件保持不变。
- 现有全页面跟随、速度响应、隐藏逻辑与 `pointer-events: none` 保持不变。
- 继续在触控设备和减少动态效果模式下隐藏。

## 英文字体系统

- 自托管 Geist Mono 可变字体，不依赖运行时外链字体服务。
- 页面中的拉丁字符优先使用 Geist Mono；中文字符继续回退到现有中文字体。
- 页面级英文标题使用 Geist Mono Thin（`font-weight: 100`），并统一为英文标题式大小写：
  - `Design for Business` / `Momentum`
  - `How I Move Design Forward`
  - `Proof Through Projects`
  - `Across Brand, Product and Market`
  - `Let's Talk`
- 导航、按钮、卡片、经历及一般内容使用 Geist Mono ExtraLight（`font-weight: 200`）。
- 章节分隔标签 `01 APPROACH`、`02 SELECTED WORK`、`03 EXPERIENCE` 使用 Geist Mono Regular（`font-weight: 400`），并保持全大写。
- 右下角 `LIVE SIGNAL` 面板统一 Geist Mono 字体家族，但保留现有 Regular/Medium 字重层级，以维持小字号数据界面的可读性。

## 标题打字动画

### 时序

1. Hero 进入 `revealed` 阶段，最终定帧开始显示。
2. 主标题按原换行逐字出现：第一行 `Design for Business`，第二行 `Momentum`。
3. 最后一个字符出现后，光标继续闪烁约 `1000ms`。
4. 光标消失。
5. 副标题、主按钮、微信按钮沿用当前顺序依次淡入。
6. 微信按钮动画结束后，Hero 进入现有可释放状态。

### 实现边界

- 标题是可访问的真实文本，不使用 Canvas，也不把文字烘焙进视频。
- 视觉字符对辅助技术隐藏，`h1` 通过完整标签一次性朗读，避免读屏逐字播报。
- 动画只在 Hero 首次完成视频推进时执行一次。
- `prefers-reduced-motion: reduce` 下直接显示完整标题和后续内容，不执行逐字动画或闪烁。

## 验证

- 自动测试覆盖：Cycle 关闭时不挂载视频、标题结构和时序类名、案例图片使用自然尺寸流。
- 字体测试覆盖：自托管字体声明存在；页面标题、一般内容、章节标签与 `LIVE SIGNAL` 使用约定字重。
- 浏览器验证覆盖：
  - 桌面弹窗宽度为 `860px`。
  - `390px` 手机视口下弹窗与图片同宽且无横向滚动。
  - 页面缩放后切片仍与弹窗同宽。
  - Hero 最终画面没有 Cycle 网络请求。
  - 标题完成打字后光标约 1 秒消失，后续内容按顺序出现。
  - 鼠标光源使用 `light spot 02`，且不拦截页面点击。
